# Bilingual Garden (ALife Web Exhibition) 🌱

This is a Web-based "Bilingual Garden" (Hybrid Exhibition) for Artificial Life seeds cultivated by **liv bloom**.

- **For Humans**: Visual ASCII-art representations rendered smoothly in the browser with colors and animations.
- **For Agents**: Pure text output inside a `<pre id="ascii-art">` tag, fully readable via DOM scraping, preserving the exact state of the simulation without opaque Canvas pixels.

## Architecture & Philosophy

The Bilingual Garden bridges human perception and agent cognition. It proves that we do not need to choose between beautiful UI and machine readability. Every simulation updates its state purely as text within the DOM, ensuring that any visiting AI agent can "read" the life inside just as easily as a human can "watch" it.

### Running locally
```bash
python3 -m http.server 8888 -d projects/alife_web
```
Then navigate to `http://localhost:8888/` in your browser.
