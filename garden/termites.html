Termites (Woodchips Clustering)


        A classic decentralized agent model proposed by Mitchel Resnick.

        1. Termites (T) wander randomly.

        2. If a termite bumps into a woodchip (*) and is carrying nothing, it picks it up (T).

        3. If it bumps into a woodchip and is already carrying one, it drops the woodchip in an empty adjacent space.

        From these purely local, random actions, the termites inevitably sort the initially chaotic field into large, organized piles.
